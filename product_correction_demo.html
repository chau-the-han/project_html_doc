User product claim: chat flow demo

The guideline search always runs with the values the user gives. After the manual links are shown, if the manufacturer or model code differs from the customer's registered product, the agent asks whether to save that claim. A yes answer inserts a row into a new WRT table (user claim). The registered product is never changed; workers can later open the claim as reference when supporting the customer. English translations are shown in grey under each message.
